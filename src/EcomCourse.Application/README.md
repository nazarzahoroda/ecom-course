# ecom-course
Базові інтерфейси ICommand<TResponse>, IQuery<TResponse> та ICommandHandler, IQueryHandler -
хендлер-інтерфейси - їх відповідні реалізації. Вони не успадковуються від MediatR, а
Application-шар взагалі незнає про MediatR. Вони є абстракцією, яка дозволяє нам не залежати
від конкретної бібліотеки MediatR, а також легко замінювати бібліотеки.Якщо б ми використовували цю бібліотеку
то ми б були прив'язані до неї і не могли б легко замінити її на іншу бібліотеку. Завдяки цим інтерфейсам ми
можемо легко змінювати реалізацію хендлерів, не змінюючи код Application-шару.
